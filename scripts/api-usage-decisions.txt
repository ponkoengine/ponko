# What was decided for each public item that nothing calls (#508), read by
# `scripts/api-usage.py report` into scripts/api-usage.md.
#
# One line per item: `<path> <decision>`. A module path decides for every
# item of the module without a line of its own. The decision starts with
# **use**, **unstable**, **remove** or **keep**:
#   use       a real use was added (a test, recipe or game calls it now);
#             the item then drops out of the list, so few lines say it
#   unstable  renamed `unstable_` (the old name deprecated for one minor)
#   remove    gone, with a `**Breaking:**` changelog entry and a migration note
#   keep      part of a type's shape that callers need even if no one calls
#             it by name yet; the reason says what it is for
#
# Items the first pass gave a real use (tests that call them by name now):
# controllers and joysticks, snapshot buffers, clock sync, latest-wins
# filters, prediction numbering, replicated i8 and quaternion fields, AI
# trees and considerations, plural tables, value schemas, world hash parts,
# tile animations, waves and currents, camera shake, rigs and pixel
# snapping, 2D skeleton graphs, rest slots, shear and constraint lookups,
# the UI's read-back and cut, touch control places and styles, frame
# budgets and collider streaming.
