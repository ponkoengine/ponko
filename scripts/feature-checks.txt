# Cargo features that may lack a check line in .github/workflows/ci.yml, one
# per line: `crate/feature kind reason`, kind being clippy, test or doc.
# scripts/check-feature-coverage.py reads this: it fails for a feature with
# no line and no entry here, and for an entry that is not needed any more.
# Prefer a line in ci.yml; an entry is for a feature with nothing a cargo
# test could check, and the reason says what checks it instead.

ponko_bench/render test Benchmark drivers are not tests (AGENTS.md); the unit tests the crate has run in cargo test --workspace, and the clippy lines build every driver
ponko_bench/audio test As ponko_bench/render: the driver needs an audio device, clippy builds it
ponko_bench/text-shaping test As ponko_bench/render
ponko_bench/video test As ponko_bench/render: the driver needs a clip, clippy builds it

ponko_bench/rapier-simd8 test As ponko_bench/rapier-parallel
