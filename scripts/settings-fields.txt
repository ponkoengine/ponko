# The Rust settings structs a C game sets through a C struct, for
# scripts/check-settings-fields.py: every public field of each has a field of the
# same name in one of its C structs (the ABI 2 struct, and the versioned `...Ex`
# descriptor beside it, STABILITY.md "Versioned descriptors"), or a line here
# that says where else C reaches it.
#
# Format:
#   struct <Name> <Rust struct> <Rust file> <C structs, comma separated>
#   <Name>.<field>  <C field | C function | ->  # reason
# `<Name>` is the public name (the Rust-only list uses it too). A C field or
# function names the counterpart when it is called something else; `-` means
# C can't reach the field: it needs a line `<Name>::<field>` on
# scripts/rust-only.txt, with its row in the "Still Rust-only" table of
# book/src/c-cpp.md.
